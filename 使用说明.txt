书镜辨章 · 长篇小说 AI 分析助手（Windows 免安装版）
版本：v1.0   适用于 Windows 10/11（64 位）

==================================================
一、它是什么
==================================================
书镜辨章 是一款单机桌面软件：导入长篇中文小说（TXT），自动分章分块，
构建结构化知识库（分层摘要、全书粗纲、人物档案、关系、设定/势力/地点、
事件时间线），并做"设定冲突检测"与"带原文证据的问答"。

本软件不联网上传你的小说，唯一外部网络依赖是你在"模型设置"里自己填写的模型 API。
所有数据存在本机，解压目录下会自动生成 data 子目录存放数据库。

重要：AI 分析结果是"带证据的参考"，不是绝对正确。冲突检测需要你人工复核后再确认。

==================================================
二、运行要求
==================================================
- Windows 10 或 Windows 11，64 位。
- 无需安装 Python、Flutter 或任何开发环境，解压即用。
- 需要能访问你配置的模型 API（你自备 base_url / api_key / 模型名）。
- 留出足够硬盘空间（百万字小说的数据库几十 MB 起，越大书越大）。

==================================================
三、首次使用流程
==================================================
1. 解压本压缩包，得到"书镜辨章"文件夹。
   不要删掉文件夹里的任何一个文件，尤其：
   - frontend.exe、flutter_windows.dll、data 子目录（前端本体）
   - backend.exe（后端本体）
   - 启动书镜辨章.bat、launcher.ps1（启动器）
   整个文件夹要放在你有读写权限的目录（不建议放 C:\Program Files 等需管理员权限的地方，
   因为后端要在文件夹内建 data 库）。

2. 双击"启动书镜辨章.bat"。
   - 首次启动后端需要 10~15 秒解包（黑底窗口会显示"[launcher] ..." 进度），请耐心等待。
   - 看到前端窗口弹出即启动成功。不要手动关闭那个黑色 launcher 窗口；
     关闭它或关闭前端主窗口都会同时退出后端。

3. 第一次打开软件，先点左侧"模型设置"：
   - 填写 base_url（例如 https://api.openai.com/v1）、api_key、模型名（例如 gpt-4o-mini）。
   - 点"测试连接"，确认提示连接成功。
   - 没有可用 API 也能导入和看本地兜底内容，但 AI 分析（摘要/抽取/问答）需要模型。

4. 回到"书架"，点"导入小说"，选择一个中文 TXT 文件。
   - 会自动检测编码、识别章节、切分块。大书首次切分需要一点时间。

5. 在"小说详情"页点"一键分析全书"。
   - 全书分析是长任务（大书可能数小时），界面会显示进度，可以在完成前关闭再回来续跑。
   - 分析完成后去各页面查看：分层摘要、全书粗纲、人物档案、关系、设定、时间线、冲突检测、问答。

6. 导出：在"导出报告"页可以把分析结果保存成 Markdown 文件到你指定的位置。

四、常见问题
==================================================
Q1 双击 bat 弹出蓝色"Windows 已保护你的电脑"SmartScreen 窗口。
A  点"更多信息" → "仍要运行"即可。本软件未做代码签名（单机小工具不做签名），
   杀毒软件可能误报，放行或加白名单。如不放心可自行核对数字签名或用源码自编译。

Q2 启动后前端一直打不开，或提示"后端在 60 秒内未就绪"。
A  常见原因：
   ① 8000 端口被占。launcher 默认用 8000；可右键"启动书镜辨章.bat"编辑，
      把 launcher.ps1 后面加 -Port 8001 改用其他端口（但前端默认连 8000，
      改端口需同步改前端配置，一般不建议；先关掉占用 8000 的程序）。
      查端口占用：cmd 里 netstat -ano | findstr :8000。
   ② backend.exe 被杀毒拦截 → 放行 backend.exe。
   ③ 首次解包慢 → 多等一会儿再重试。

Q3 汉字显示成"天"上长下短、或笔画断开。
A  本版本已指定中文字体，正常情况不会出现。若仍异常，确认系统未卸载"微软雅黑"字体。

Q4 分析很慢 / 卡在某一步。
A  全书分析是长任务，百万字以上可能数小时、数百次模型调用，请确保 API 额度充足。
   支持取消、续跑。中途关闭软件下次进来可继续。

Q5 提示模型分析失败、结果为空。
A  检查：① 模型设置里的 base_url / api_key / 模型名是否正确、是否余额充足；
   ② 网络能否访问该 API；② 失败的不会写缓存，改好配置后重试即可。

Q6 关掉前端后再次启动提示端口被占。
A  偶发情况下后端子进程未及时退出。等几秒再启动；或打开任务管理器结束 backend.exe 进程。

==================================================
五、数据与卸载
==================================================
- 你的所有数据存在"书镜辨章"文件夹下的 data 子目录（数据库文件）。
- 卸载：整个"书镜辨章"文件夹删除即可，无残留到注册表或系统目录。
- 想备份：复制整个文件夹即可（先关闭软件）。
